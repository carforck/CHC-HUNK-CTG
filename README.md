# Club Hunk Cartagena · Plataforma digital

Propuesta de plataforma web para **Club Hunk Cartagena (CHC)**: sitio oficial con el branding del club, registro de miembros con ficha de emergencia, rodadas y viajes, vitrina de emprendimientos y Academia CHC.

- `propuesta/` — presentación de la propuesta (HTML estático)
- `recursos/` — logo, fotos y ficha de marca ([MARCA.md](recursos/MARCA.md))

Desarrollado por [Carlos Carranza](https://github.com/carforck) · miembro CHC.
